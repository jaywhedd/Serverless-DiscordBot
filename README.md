# Serverless-DiscordBot
 A serverless Discord bot on AWS where users award each other daily accolades that build weekly credit totals. Each accolade category can be awarded to one user per day. A weekly scheduled job finalizes the leaderboard, automatically assigns rank roles (#1, #2, #3) through the Discord API, and resets weekly credits. Built with Python, Lambda, API Gateway, DynamoDB, and EventBridge and designed to run mostly within the AWS free tier.
