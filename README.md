# Serverless-DiscordBot
 A serverless Discord bot on AWS where users award each other accolades that build weekly and lifetime credit totals. Built with Python, Lambda, API Gateway, DynamoDB, and EventBridge so it is command-driven interactions run through API Gateway, while a weekly scheduled job finalizes the leaderboard and automatically assigns rank roles (#1, #2, #3) via the Discord API. Runs mostly within AWS free tier.
